# ADQUIMIA · releases

Descargas de **ADQUIMIA** (gráficas comerciales desde planillas Excel).

- **ADQUIMIA_x.y.z_x64-setup.exe**: instalador de la app para Windows.
- **ADQUIMIA-plugin-x.y.z.ccx**: plugin para Photoshop 26 (se instala aparte).

La app se actualiza sola a partir de estas versiones. Este repositorio solo contiene las versiones publicadas.
